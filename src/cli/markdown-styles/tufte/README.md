# Tufte CSS source

Vendored from https://github.com/edwardtufte/tufte-css at
`b5d7b7bbe5ce9c4c50fcfad4f19ee3646cfd7ae1`.

The upstream stylesheet and referenced ET Book fonts are unchanged. The upstream
MIT license is included in `LICENSE`. `../academic.css` adapts the page container
and public color/font variables for Devjar. Only Academic exports these assets.
Math rendering is provided separately by Devjar's `--math` option.
