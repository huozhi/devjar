# Measuring uncertainty

[Abstract](./index.md) · [Method](./method.md) · [Results](./results.md)

## Abstract

A single reading gives a value. Repeated readings help describe how much that value varies.

Three observations of the same reference sample illustrate a simple procedure: record, summarize, and report the spread alongside the mean.

How closely do repeated measurements agree under the same conditions?
