# Learning to Ask Better Questions

## The idea

A question becomes useful when we can imagine what evidence would answer it. Start with something you can observe, then change one thing at a time.

> **Try this:** replace “Why does this happen?” with “What changes when I do this?”

## A small exercise

1. Choose two plants of the same kind.
2. Place one near a window and one farther away.
3. Keep their water and soil the same.
4. Record what you notice for a week.
